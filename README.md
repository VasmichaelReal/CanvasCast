# CanvasCast

Інклюзивний AI-гід для мистецьких просторів: художня аудіодескрипція картин для людей із
порушеннями зору. Власник галереї завантажує фото — система пише й озвучує описи; відвідувач
сканує QR-код і слухає на власному телефоні, зокрема без інтернету. Без реєстрації й без
встановлення застосунку.

Архітектура та план — у [PLAN.md](PLAN.md).

## Швидкий старт

Потрібні Node.js 22+ і Docker.

```bash
npm install                 # залежності + генерація Prisma-клієнта
cp .env.example .env        # локальні налаштування (уже придатні до роботи)
npm run infra:up            # Postgres, Redis і S3-сховище (RustFS) в Docker
npm run db:migrate          # створити таблиці
npm run dev                 # веб (http://localhost:3000) + воркер генерації
```

Відкрийте http://localhost:3000, створіть галерею, завантажте фото й натисніть
«Згенерувати описи».

### Підключення AI (безкоштовно)

Без ключа застосунок працює в **демо-режимі**: увесь цикл проходить, але тексти описів —
заглушка. Щоб отримати справжні описи:

1. На https://aistudio.google.com натисніть **Get API key** (картка не потрібна).
2. Впишіть ключ у `.env`: `GEMINI_API_KEY=...`
3. Перезапустіть `npm run dev`.

Озвучення за замовчуванням іде через безкоштовні нейроголоси Microsoft Edge (`TTS_PROVIDER=edge`,
ключ не потрібен). Це неофіційний доступ — для продакшну варто перейти на платного провайдера.
Офіційна безкоштовна альтернатива — `TTS_PROVIDER=gemini` (той самий ключ, малі денні ліміти).

### Перевірка на телефоні

Офлайн-режим (service worker) браузери вмикають лише на `https://` або `localhost`. Щоб
перевірити на телефоні, відкрийте застосунок через HTTPS-тунель (наприклад, `cloudflared tunnel
--url http://localhost:3000`) і вкажіть отриману адресу в `APP_URL` — тоді QR-код вестиме на неї.

## Деплой на безкоштовний хостинг

Схема: веб — Vercel, воркер — Render, база — Neon, Redis — Upstash, файли — Supabase Storage
(або будь-яке S3-сумісне сховище). Vercel і Render самі перезбирають застосунок після кожного
`git push` у GitHub. Ця схема ще не перевірена на справжніх сервісах.

1. **Сервіси даних.** Створіть базу в Neon, Redis в Upstash (адреса `rediss://…`) і бакет
   `canvascast` у сховищі з S3-ключами.
2. **`.env.production`.** Скопіюйте `.env.example` у `.env.production` (файл не потрапляє в git)
   і впишіть туди `DATABASE_URL`, `REDIS_URL`, `S3_*`, `GEMINI_API_KEY`.
3. **Міграція.** `npm run db:migrate:prod` створює таблиці в хмарній базі.
4. **Воркер на Render.** New → Blueprint → цей репозиторій: налаштування бере з `render.yaml`,
   значення секретів вводяться в панелі. Запам'ятайте адресу сервісу (`https://….onrender.com`).
5. **Веб на Vercel.** Імпортуйте репозиторій, Root Directory — `apps/web`, решта за
   замовчуванням. У змінні середовища додайте те саме, що в `.env.production`, а також
   `WORKER_URL` (адреса воркера з кроку 4) і `APP_URL` (адреса сайту, яку видасть Vercel).

Особливості безкоштовних тарифів, які враховано в коді:
- Vercel обмежує тіло запиту 4,5 МБ — редактор зменшує великі фото в браузері й надсилає їх
  по одному.
- Render присипляє сервіс без запитів — веб будить воркер через `WORKER_URL`, коли ставить
  задачу; перша генерація після паузи стартує приблизно на хвилину довше.
- Upstash рахує команди — воркер рідко опитує порожню чергу.

## Команди

| Команда | Що робить |
|---|---|
| `npm run dev` | веб і воркер у режимі розробки |
| `npm run build` / `npm start` | продакшн-збірка й запуск |
| `npm test` | юніт-тести (Vitest) |
| `npm run typecheck` | перевірка типів у всіх пакетах |
| `npm run infra:up` / `infra:down` | підняти / зупинити локальну інфраструктуру |
| `npm run db:migrate` | застосувати міграції БД |
| `npm run db:migrate:prod` | те саме для бази з `.env.production` |

## Структура

```
apps/web        Next.js: сторінки (/, /e/<editToken>, /g/<viewToken>) і REST API
apps/worker     воркер BullMQ: опис (LLM) → озвучення (TTS) → збереження
packages/core   доменна логіка: промпт «стилю CanvasCast», токени, схеми, типи
packages/db     схема Prisma, міграції, клієнт
packages/providers  адаптери LLMProvider (Gemini, mock) і TtsProvider (Edge, Gemini, mock)
packages/storage    S3-сумісне сховище (RustFS локально)
packages/queue      черга BullMQ та обмеження частоти запитів
infra           docker-compose.yml
```

## Як замінити AI-провайдера

Реалізуйте інтерфейс `LLMProvider` або `TtsProvider` у `packages/providers` і додайте гілку у
відповідну фабрику (`createLLMProvider` / `createTtsProvider`). Решта системи не змінюється.

## Доступ без облікових записів

- `/g/<viewToken>` — посилання для відвідувачів (його кодує QR).
- `/e/<editToken>` — секретне посилання власника. Втрачене посилання відновити неможливо;
  браузер, у якому створено галерею, пам'ятає його й показує на головній сторінці.
