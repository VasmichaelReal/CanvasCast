# Тестові документи для імпорту картин

Набір файлів для ручної перевірки секції «Імпорт із документа» в редакторі галереї. Відкрийте
редактор, виберіть файл у полі «Документ» і звірте картки з таблицею нижче.

Усі картини, автори й події вигадані. «Фото» картин — абстрактні зображення, згенеровані
скриптом, щоб у наборі не було чужих творів.

```bash
python3 test-documents/generate.py   # перегенерувати все (потрібні Pillow і LibreOffice)
```

`24-too-big.pdf` (11 МБ) не зберігається в git — його створює скрипт.

## Що перевірити в інтерфейсі

- **Зіставлення з наявними фото.** Спершу завантажте кілька фото звичайним способом, потім
  імпортуйте `04-list.xlsx`. З'явиться кнопка «Зіставити з наявними фото по порядку», і картки
  без фото по черзі заповнять картини без назви.
- **Автозіставлення за назвою.** Якщо в галереї вже є картина з назвою «Червоні маки», то після
  імпорту `04-list.xlsx` її картка одразу буде спрямована в неї («Заповнити картину N»).
- **Картка без фото.** Натисніть «Додати до галереї» з карткою «Нічний потяг» без фото. Вона
  підсвітиться з проханням додати фото або вибрати наявну картину, а решта не додасться, поки
  це не виправлено.
- **Демо-режим** (без `GEMINI_API_KEY`). Документ розкладається на картки механічно, по
  абзацах, а скан PDF не розпізнається — це очікувано.

Результати з таблиці перевірено на `gemini-flash-lite-latest` (резервна модель) і, для 13,
на `gemini-flash-latest`. Модель може відповідати трохи по-різному: дрібні розбіжності в
контексті — норма, а от вигадані факти, зайві чи пропущені картки — ні.
